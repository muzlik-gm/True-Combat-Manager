[SIZE=6][B]🎯 Overview[/B][/SIZE]

True Combat Manager is a complete PvP management system built for competitive Minecraft servers.  
It tracks fights with precision, enforces intelligent restrictions, prevents combat logging, and includes fully customizable visual effects for a polished player experience.

Designed with performance in mind using async processing, lag compensation, and a thread-safe architecture. Ideal for Practice, KitPvP, Factions, or any PvP-focused gameplay environment.
