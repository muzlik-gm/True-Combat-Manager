[SIZE=6][B]🎯 Overview[/B][/SIZE]

True Combat Manager is a complete PvP management system built for competitive Minecraft servers.  
It tracks fights with precision, enforces intelligent restrictions, prevents combat logging, and includes fully customizable visual effects for a polished player experience.

Designed with performance in mind using async processing, lag compensation, and a thread-safe architecture. Ideal for Practice, KitPvP, Factions, or any PvP-focused gameplay environment.

[SIZE=6][B]⚙️ Configuration (Example)[/B][/SIZE]

[CODE=yaml]
# Config excerpt...
general:
  enabled: true

combat:
  duration: 30

database:
  type: "SQLITE"              # SQLITE or MYSQL
  mysql:
    host: "localhost"
    port: 3306
    database: "pvpcombat"

newbie-protection:
  enabled: true
  xp-level-threshold: 3

restrictions:
  enderpearl:
    enabled: true
    cooldown: 10
  golden-apple:
    cooldown: 3
    combat-cooldown-multiplier: 1.5

visual:
  themes:
    default-theme: "default"

performance:
  async:
    enabled: true
  lag:
    enabled: true
    tps-threshold: 18.0

statistics:
  enabled: true

logging:
  console-enabled: false      # Disable for best performance
[/CODE]
