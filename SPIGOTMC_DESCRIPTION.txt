[SIZE=6][B]Overview[/B][/SIZE]

True Combat Manager is a feature-rich combat management system designed for competitive Minecraft PvP servers. It focuses on accurate combat detection, preventing PvP abuse, providing clear player feedback, interactive statistics GUIs, and persistent data tracking.

[IMG]https://i.imgur.com/9Zy4QZX.png[/IMG]

[SIZE=6][B]✨ What's New in v1.2.1[/B][/SIZE]

[SIZE=5][B]Dual Grace Period System[/B][/SIZE]

• [B]Bad-internet grace period[/B] — longer, more lenient window for players who lost connection unexpectedly. Detected automatically from the quit reason.
• [B]Intentional grace period[/B] — shorter window for players who pressed Disconnect or closed the game.
• Each type has its own [ICODE]grace-seconds[/ICODE], messages, and can be enabled/disabled independently.

[SIZE=5][B]Repeat-Logout Abuse Prevention[/B][/SIZE]

• Tracks each player's disconnect history in a rolling time window.
• If a player disconnects too many times within the window, they are killed immediately on the next logout — no grace period granted.
• Fully configurable: [ICODE]max-count[/ICODE], [ICODE]window-seconds[/ICODE], messages.

[SIZE=5][B]Bypass-Totem Config[/B][/SIZE]

• [ICODE]bypass-totem: true[/ICODE] (default) — punishment kills bypass the Totem of Undying.
• [ICODE]bypass-totem: false[/ICODE] — a held totem can proc and save the player.

[SIZE=5][B]Per-Player Theme Persistence[/B][/SIZE]

• Theme selections saved to the database and restored across sessions.
• [ICODE]/combat toggle-style[/ICODE] works both in and out of combat.

[SIZE=5][B]Bug Fixes[/B][/SIZE]

• Fixed inventory duplication (armor dropped twice)
• Fixed double bossbar on reconnect
• Fixed player not killed after grace period
• Fixed concurrent update race in player data
• Fixed sound profiles not updating on reload

[SIZE=6][B]Disconnect Protection Flow[/B][/SIZE]

[B]Grace period expires, player still offline:[/B]
1. Inventory dropped at disconnect location immediately
2. Win/loss recorded, opponent notified and rewarded
3. Player killed on next login (inventory cleared first)

[B]Player rejoins with pending punishment:[/B]
1. Live inventory cleared
2. Player killed (totem bypass configurable)
3. Opponent receives reminder message

[SIZE=6][B]Commands[/B][/SIZE]

[SIZE=5][B]Player Commands[/B][/SIZE]

[CODE]
/combat status              - View your combat status
/combat stats               - Open your combat statistics GUI
/combat summary             - View latest fight summary
/combat toggle-style        - Change visual theme (works anytime)
[/CODE]

[SIZE=5][B]Admin Commands[/B][/SIZE]

[CODE]
/combat reload              - Reload configuration
/combat inspect <player>    - View real-time combat info
/combat summary <player>    - Open player's stats GUI
/combatadmin stats          - Open server statistics GUI
/combat clear <player>      - Force-end combat
/combat protection <player> <seconds> - Grant immunity
/combat debug               - Toggle debug mode
/combat logging <on|off>    - Toggle console logging
[/CODE]

[SIZE=6][B]Configuration Example[/B][/SIZE]

[CODE=yaml]
combat:
  duration: 10
  disconnect-protection:
    enabled: true
    bad-internet:
      grace-seconds: 30
    intentional:
      grace-seconds: 10
    repeat-logout:
      enabled: true
      max-count: 2
      window-seconds: 240
    punishment:
      drop-inventory: true
      bypass-totem: true

visual:
  themes:
    default-theme: "clean"
  sounds:
    profile: "default"

database:
  type: "sqlite"
[/CODE]

All settings reload instantly with [ICODE]/combat reload[/ICODE].

[SIZE=6][B]Installation[/B][/SIZE]

1. Download the plugin JAR
2. Place it inside the [ICODE]plugins[/ICODE] folder
3. Restart the server
4. Configure settings if needed
5. Run [ICODE]/combat reload[/ICODE]

[B]No additional setup required[/B] — SQLite works out of the box.
